# GST-Computation_Dashbord_Automation-in-Excel
Automated GST Computation &amp; ITC Set-off Tool built in Excel. Calculates GST liability, automates IGST-CGST-SGST utilization as per GST rules, generates dashboards, and provides accurate GST payable reporting using advanced Excel formulas and automation. This automation reduces manual data entry time by 80%
